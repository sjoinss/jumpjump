# 점프점프 — UI 분석 및 구성안

> 「UI제작원칙」 2번(분석)과 26번(결과물)에 맞춰 정리한 문서입니다. 기준은 `dot-jump-climb-spec.md`이고, 구현하면서 이 문서도 같이 갱신합니다.

## 변경 사항 (2026-09-30, 사용자 결정 — 기획서보다 우선)

- **타이틀·첫 실행 선택 화면 없음**: 게임 장면 그대로 캐릭터가 바닥에 서 있고, 좌우에 카드 두 장 「시작하기(기본 캐릭터로)」「캐릭터 만들기」. 엔진 Phase에 `ready`를 추가해 처리
- **HUD**: 오른쪽 위에 ⚙ 설정 → ‖ 일시정지 순. 둘 다 아이콘만(스크린리더 이름 + 툴팁 `title` 제공). 설정은 시작 장면·게임 중 모두 열 수 있고, 게임 중에 열면 자동 일시정지 후 닫으면 일시정지 메뉴로 돌아옴
- **디자인 방향 변경**: 무난한 SaaS풍 → **귀여운 파스텔 게임풍**. 파스텔 채우기 + 잉크색 두꺼운 외곽선 + 아래 두께(눌리는 버튼), 둥근 게임 폰트(Jua, 빌드 때 번들), 도트 아이콘, 연한 도트 무늬 배경
- 일시정지 메뉴의 "타이틀로" → "처음으로"(시작 장면으로 돌아감)
- **테마 3종** (설정 → 테마, 즉시 적용·자동 저장): 도트 놀이터(기본) / 솜사탕(연한 분홍 외곽선, 더 둥글게) / 꿈나라(라벤더·하늘빛, 달과 별). UI 색은 `tokens.css`의 `[data-theme]`, 게임 장면 색은 `src/game/themes.ts`. 외곽선 색(`--color-line`)과 글자색(`--color-ink`)을 분리해서 어느 테마든 글자 대비 AA 유지. `settings.theme`은 v1에 추가된 항목이라 없으면 기본 테마로 읽음(마이그레이션 없음)
- **에디터 키보드 그리기 없음**: 도트는 터치·마우스로만 그린다(방향키 커서·스페이스 칠하기 제외). 메뉴·버튼·탭·대화창의 키보드 조작과 Ctrl+Z 같은 단축키는 유지
- **조작법 안내(4단계)**: 첫 판에서 "시작하기"를 누를 때 한 번만 대화창으로 표시. 터치 기기는 드래그, 마우스·키보드 기기는 ←→/A·D + 마우스 안내(둘 다 있으면 둘 다). ✕로 닫아도 본 것으로 기록. 기본 캐릭터 고르기는 별도 화면 없이 에디터의 "불러오기"에서
- **이미지 불러오기(5단계)**: 에디터 캐릭터 탭의 「불러오기·크기 → 내 이미지 불러오기」, 이미지 프레임의 「이미지 바꾸기」, PC는 캐릭터 탭에 파일 끌어다 놓기. 조정 화면은 에디터 위에 덮는 전체 화면(대화창보다 공간이 필요해서)
- **데이터 관리(6단계)**: 설정 → 데이터 관리. 내보내기 기본은 그림만(캐릭터·발판·동료·팔레트), "전체 백업"은 설정·최고 기록까지. 불러오기 때 온보딩 기록은 이 기기 것을 유지. 주기적 백업 안내는 직접 그린 그림이 있고 마지막 내보내기(또는 안내)에서 14일이 지나면 시작 화면에 표시
- **점수 = 높이(m)** (2026-10-01): "처음 밟은 발판마다 +1" 대신, 이번 판에서 대열 맨 아래 줄 발밑이 올라간 가장 높은 곳을 m로 표시(내림, 떨어져도 줄지 않음). 1m = 캐릭터 키 72px(`CONFIG.score.pxPerMeter`). HUD·게임오버·최고 기록은 "123m", 스크린리더는 10m마다. 기존 체감 속도에 맞춰 높이 기준도 m로 옮김: 지역 지상 75m / 하늘 260m / 우주 600m(섞임 ±25m), 동료 후보 25·75·175·350·650m 이후 300m 간격, 고점프 15m·일회용 35m부터. 이전에 저장된 최고 기록(발판 수)은 그대로 두고 새 기록으로 덮어씀
- **동료 그리기(10단계)**: 주인공·발판 에디터(`EditorScreen`)를 그대로 쓰고 `companion` 모드면 탭 없이 동료 한 명 + 이름(선택, 12자) + 「주인공 가이드」 토글, 착지 프레임엔 「내 기본 그림 깔기」(주인공 편집의 「기본 그림 깔기」와 라벨 구분). "불러오기·크기"에서 동료는 기본 캐릭터 대신 「주인공 그림 가져오기」. 게임 중: 선택창 "예, 그릴래요"(빈 슬롯) / "예"·"수정하기"(그림 있음) → 게임 멈춘 채 그리기 → 완료하면 슬롯 저장 후 합류(11단계에서 미니게임이 끼어듦). "그만 그리기"는 초안(슬롯별 `editor.draft.companion.N`)을 남기고 후보 유지, 거절로 세지 않음. 설정 → 동료: 최대 인원(0~5, 다음 판부터, 자동 설정 표시), 슬롯 1~5 그리기/수정·삭제, 전부 삭제(확인창, 기본 포커스 취소)

아래 A~H 중 이와 다른 부분은 위 내용이 우선합니다.

| 5 | 주요 CTA | 타이틀 "시작", 게임오버 "다시 하기", 에디터 "완료(저장)", 동료 선택창 "예" |

| 7 | 사용자 흐름 | 첫 실행 선택 → (기본 캐릭터 고르기 \| 에디터) → 조작법 안내 1회 → 플레이 → (동료 후보 → 선택창 → 그리기 → 미니게임 → 결과) → 게임오버 → 다시 하기 / 저장 / 에디터 |
| 8 | 기기별 레이아웃 | 모바일(≤480px): 전체화면 게임, 설정은 전체화면 시트. 태블릿·PC(>480px): 가운데 세로 프레임 + 파스텔 배경. 좌우 여백에 최고 기록·설치 버튼(공간이 있을 때만) |
| 9 | 접근성 문제 | 캔버스는 스크린리더가 읽지 못함 → 점수·배너·카운트다운·결과를 텍스트/`aria-live`로 따로 전달. 에디터는 방향키+스페이스로 그리기. 특수 발판·후보·스위치 상태를 색으로만 구분하지 않기. 캔버스 안의 조작은 키보드로 대체 가능해야 함 |

| 11 | 일관성 | 새 프로젝트라 기존 디자인 시스템이 없음 → `tokens.css`와 공통 컴포넌트(`components/ui`)를 1단계에서 만들고 모든 화면이 이것만 사용 |

## E. 반응형 전략 (원칙 26-4)

- **기준 해상도**: 게임은 논리 폭 360 고정, 높이 640~840. `scale = min(화면폭/360, 화면높이/640)`로 맞추고, 남는 영역은 배경으로 채움(레터박스 없음)
- **≤480px (360·390 모바일)**: 게임 전체화면. 메뉴 화면은 한 열, 버튼은 폭 100%, 설정은 전체화면
- **>480px (768 태블릿 ~ 1440 데스크톱)**: 가운데 세로 프레임. 배율은 1, 1.5, 2… 0.5 단위로 스냅하고 남는 높이는 논리 높이(최대 840)로 흡수. 프레임 좌우에 240px 이상 여유가 있으면 최고 기록·설치 버튼 표시, 없으면 숨기고 타이틀 화면에서 보여줌
- **메뉴 화면(설정·에디터)**: 프레임 안에서 스크롤. 가로 스크롤 없음, 긴 텍스트는 줄바꿈
- **가로 모드(모바일)**: "세로로 돌려주세요" 안내 표시
- **길쭉한 폰(20:9)**: 논리 높이가 840을 넘는 부분은 배경만 그림

## G. 접근성 전략 (원칙 26-5)

- 화면마다 `<main>` + `<h1>` 하나, 섹션은 `<section>` + `<h2>`
- 포커스 링은 절대 지우지 않음(`:focus-visible` 3px 링). 화면이 바뀌면 새 화면의 `<h1>`로 포커스 이동
- 캔버스: `role="img"`가 아니라 `aria-label`을 단 조작 영역 + 텍스트 HUD. 점수·배너·카운트다운·결과는 공용 live region으로 전달
- 모든 조작을 키보드로 가능하게: 인게임(←→/A·D, Enter/Space, Esc/P), 에디터(방향키 + 스페이스), 다이얼로그(Tab 순환, ESC)
- 색에 기대지 않기: 스위치는 텍스트, 특수 발판은 도형 표식, 후보는 테두리·흔들림, 토스트는 기호 + 문장
- 대비: 본문 AA(4.5:1) 이상, 큰 글씨·UI 경계 3:1 이상. HUD 텍스트는 외곽선/반투명 판 위에 표시
- `prefers-reduced-motion`: 배너 슬라이드·흔들림·파티클·PC 배경 장식 애니메이션 끔

## H. 디자인 방향 (원칙 26-7) — 귀여운 파스텔 게임풍

- **형태 언어**: 파스텔 채우기 + 잉크색(`--color-ink`) 3px 외곽선 + 아래 4~6px 두께. 누르면 두께만큼 내려감. 모서리 14~28px
- **색**: 딸기우유(primary) · 라벤더(secondary) · 민트 · 버터 · 하늘 · 크림. 파스텔은 채우기에만 쓰고 글자는 잉크색 → 모든 조합 6:1 이상. 상태색(success/warning/error)은 기호와 함께
- **글자**: 제목·버튼·HUD·숫자는 번들 폰트 Jua(1종), 긴 설명은 시스템 한글 폰트. 크기 34/26/21/18/16/14, 14px 미만 없음
- **장식**: 연한 도트 무늬 배경, 도트 아이콘(`PixelIcon`), 캔버스는 계단식 파스텔 띠 + 도트 구름·반짝이 + 풀밭 바닥. 로고만 살짝 둥실
- **모션**: 버튼 누름 120ms, 다이얼로그·토스트·카드 등장은 살짝 튀는 ease(`--ease-pop`). `prefers-reduced-motion`이면 로고 둥실·구름 흐름·캐릭터 제자리 점프 끔
